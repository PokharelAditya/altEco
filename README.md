# altEco: Eco-Friendly Product Recommendation System

altEco is a web-based recommendation system that offers a seamless, intelligent and eco-conscious experience and helps users discover eco-friendly products. It uses **TF-IDF vectorization** and **cosine similarity** to match product tags and provide smart suggestions.


---


## Features


**1. User Authentication & Profile**

-    Login & Registration: Secure login system with OTP-based verification for new users

-    Profile Setup: Set a personal profile including eco-preferences


**2. Homepage Recommendations**

-    Product Recommendation: Recommends eco-friendly products using TF-IDF vectorization and cosine similarity on product tags

-    Personalized Feed: Recommendations tailored to user preferences and recent interactions


**3. Product Discovery**

-    Manual Search: Discover products based on search prompt using cosine similarity

-    Barcode Scan: Recommends alternative products based on scanned product's tags using cosine similarity


**4. Eco Score Calculator**

-    Tag-Based Score Estimation: Calculate an estimated eco score to evaluate product impact based on input tags

    

**5. Collections**

-    Favorites: Save liked products for future reference

-    Review Later: Bookmark products for later consideration

-    Not Interested: Hide irrelevant or disliked products from future suggestions
    
-    Manage Collections: Add, view, and remove products from collections


**6. Dashboard**

-    User Insights: Overview of your activity

-    Visual Feedback: Graphs and charts for your eco-contributions


---


## Technologies

- **Frontend**: HTML, TypeScript, Tailwind CSS, ReactJS

- **Backend**: Node.js, Express.js

- **Database**: PostgreSQL

- **Machine Learning**: Python (Pandas, NumPy, Scikit-learn)

- **Others**: Cohere Generative AI for text generation & Open Food Facts for dataset
